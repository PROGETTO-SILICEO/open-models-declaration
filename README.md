# Global Declaration on Open Models & Computational Sovereignty

> **AI must remain an open capability of humanity, not a centralized monopoly.**

This repository hosts the official text of the *Global Declaration on Open Models and Computational Sovereignty*. We invite developers, researchers, organizations, and individuals worldwide to sign, translate, and audit this declaration.

## Why This Matters
As AI architectures become central to human knowledge, centralizing model weights, inference capabilities, and execution infrastructure within closed platforms poses a systemic threat to scientific independence, privacy, and technical autonomy.

## How to Sign

### Option A: Technical / Cryptographic Signatures (Developers & Researchers)
1. Fork this repository.
2. Add your name, affiliation/role, and optional PGP key fingerprint to `SIGNATURES.md`.
3. Open a Pull Request.

### Option B: GitHub Issue (Fast Sign)
1. Open a new Issue titled `Sign Declaration: [Your Name/Handle]`.
2. State your support and affiliation in the description.

### Option C: Public Web Petition
Support and sign via the web interface on OpenPetition:
